# Agile Application Projects

I designed these three applications as portfolio projects using an iterative
Agile workflow. For each one I defined a product goal, wrote user stories,
prioritised a small backlog, implemented a vertical slice, and documented the
acceptance criteria and next sprint.

| Application | Platform | Main engineering focus |
| --- | --- | --- |
| FocusDesk | macOS / Windows | Cross-platform desktop architecture |
| FocusHabit iOS | iOS | SwiftUI state-driven interface |
| FocusHabit Android | Android | Kotlin and Jetpack Compose |
