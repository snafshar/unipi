# Machine Learning Projects

I implemented five dependency-light machine-learning algorithms from scratch.
I use them to understand the optimisation, distance, impurity, probability,
and gradient calculations instead of hiding the work behind a high-level
library. These are educational baselines, not claims of production accuracy.

I also added automated smoke tests for the logistic-regression, K-Means, and
Naive Bayes implementations. The tests give me a repeatable correctness check
before I change the algorithms or add real datasets.
