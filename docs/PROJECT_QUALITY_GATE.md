# Project Quality Gate

Before marking a coursework or research repository complete:

- [ ] A clean checkout has a clear starting point.
- [ ] Inputs, outputs, and assumptions are documented.
- [ ] At least one normal case and one boundary case are verified.
- [ ] Experiments can be repeated with recorded settings.
- [ ] Results distinguish measured facts from interpretation.
- [ ] No credentials, private data, or machine-specific paths are committed.

## Evidence
Record the commands run, their outcome, and the commit tested.
