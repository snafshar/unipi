# RESEARCH RISK REGISTER

Purpose: provide a repeatable, lightweight workflow for this repository's unipi work.

## Checklist

- [ ] State the problem and expected outcome before implementation.
- [ ] Keep inputs, units, assumptions, and edge cases explicit.
- [ ] Add a small reproducible example or test case.
- [ ] Record the command used to run the check and its result.
- [ ] Note limitations and follow-up work rather than hiding uncertainty.

## Acceptance criteria

1. The steps can be followed from a clean checkout.
2. Invalid or missing inputs produce a clear failure message.
3. Results are interpretable and include units where relevant.
4. Changes remain focused and are documented for future contributors.
