# Portfolio Checklist

A lightweight checklist for keeping university coursework and technical projects reproducible.

## Before publishing
- State the problem and expected result.
- Record language, runtime, and dependencies.
- Include a small reproducible example.
- Separate source code, experiments, and generated output.
- Explain how correctness was checked.

## Before submission
- Build from a clean checkout.
- Run the documented tests or examples.
- Remove credentials and machine-specific paths.
- Record the commit used for the submission.
