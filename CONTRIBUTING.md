# Contributing to My Portfolio

I use this repository to practise disciplined software engineering alongside
algorithm and systems work.

## Development workflow

1. I define a small user story or engineering question.
2. I implement the smallest testable change.
3. I run the relevant tests and record assumptions.
4. I review the diff for correctness, portability, and clarity.
5. I document the result and the next experiment.

## Commit guidelines

I prefer focused commits with imperative messages, for example:

- `Add tests for Naive Bayes smoothing`
- `Document blocked multiplication benchmark`
- `Add CI build for C++ portfolio`

I avoid committing generated build directories, caches, credentials, or
machine-specific files.
